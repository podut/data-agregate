Viziune de Ansamblu

Backend: rss-ingestor-service

O arhitectură modernă bazată pe FastAPI și Python care automatizează colectarea știrilor prin feed-uri RSS și Google News. Fiecare articol este procesat în fundal folosind modele de limbaj avansate (Google Gemini).

Frontend: Android DataAgregate

Aplicație nativă dezvoltată cu Kotlin și Jetpack Compose, oferind o experiență utilizator fluidă, tematică Material 3 și suport offline complet prin Room Database.

Stack Tehnologic

  • Python 3.10+ & FastAPI
  • Google Gemini 2.5 Pro
  • Kotlin & Jetpack Compose
  • SQLite & Room Persistence

Performanță

FastAPI asigură latențe minime pentru aplicația mobilă.

AI Native

Sumarizare și scoring automat direct în backend.

Offline First

Citește știrile salvate chiar și fără conexiune.

Modern UI

Design bazat pe Material 3 și animații fluide.

Backend Deep Dive

Core / API

main.py

Punctul de intrare al aplicației. Configurează FastAPI, gestionează ciclul de viață pentru pornirea scheduler-ului și definește rutele REST.

Intelligence

ai_service.py

Inima inteligentă a sistemului. Gestionează comunicarea cu Google Gemini. Generează rezumate în română și calculează scoruri.

Networking

rss_service.py

Colectează datele brute. Parsează feed-urile RSS folosind feedparser și coordonează fluxul de procesare al articolelor.

Persistence

database.py

Abstracția bazei de date SQLite. Conține funcțiile CRUD pentru articole, surse RSS și setările globale ale aplicației.

Automation

scheduler_task.py

Gestionează job-urile în fundal cu APScheduler, asigurând că știrile sunt actualizate automat la intervale regulate.

Helper

utils.py

Funcții auxiliare: curățarea conținutului HTML, generarea URL-urilor Google News și algoritmi de ranking a articolelor.

Configuration

config.py

Centralizează setările mediului: chei API, căi către baza de date (Docker/Local) și prompt-urile pentru AI.

Script

backfill_images.py

Script asincron care face scraping pentru a recupera imaginile lipsă ale articolelor deja procesate.

DevOps

migrate_db.py

Evoluția schemei bazei de date. Permite adăugarea de coloane noi fără pierderi de date.

Schema

models.py

Modele Pydantic pentru validarea formatului cererilor API venite de la aplicația mobilă.

Testing

test_api.py

Script de testare automatizată care simulează interacțiunile aplicației cu serverul FastAPI.
